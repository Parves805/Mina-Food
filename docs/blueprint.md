# **App Name**: GreenBasket

## Core Features:

- Product Catalog: Display a searchable catalog of organic food products, filtered by category, price, and certification.
- User Authentication: Allow users to register, log in, and manage their profiles, including order history and saved addresses.
- Shopping Cart and Checkout: Enable users to add products to a shopping cart, apply coupons, select delivery slots, and complete the checkout process using mocked payment integrations.
- Admin Dashboard: Provide an admin interface for managing products, categories, orders, coupons, and user accounts.
- Order Management: Allow users to view their order history, and admins to update order statuses.
- Recommendations: AI-powered tool recommends products that users might like, based on browsing history.
- Database Integration: Data persistence to the MongoDB database, following provided schemas.

## Style Guidelines:

- Primary color: Natural green (#4CAF50) for an organic feel.
- Accent color: Earthy brown (#000000) for highlights and accents.
- Background color: Light beige (#F7F6E7) to provide a soft, natural backdrop.
- Body and headline font: 'Poppins' sans-serif for a clean and modern look.
- Responsive, mobile-first design using Tailwind CSS grid and flexbox.
- Use simple, line-based icons to represent product categories and UI actions.
- Subtle animations on hover states and transitions to enhance user experience.
